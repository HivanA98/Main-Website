Platinum Challenge 3 classes · 10,933 rows · reproducible

Three-class sentiment, with the workings shown

Negative, neutral or positive. The interesting part is not the classifier but the benchmark beside it, which regenerates every number quoted in the repository — baseline, ablation and model comparison — so none of them has to be taken on trust.

View the code CI runs

What is in it

  • sentiment_pipeline.py — the final pipeline: train, evaluate, predict, save and load.
  • benchmark.py — reproduces every figure in the repository, including the baseline and the ablation.
  • sentiment_model.pkl — the trained model, ready to load.

Classification report

The neutral class is the hard one: it is the smallest and the most ambiguous, and it is where the original recipe lost most of its score.
