Indonesian NLP 2 challenges · Binar Academy · rebuilt from scratch

Better methodology beat a bigger model

Two sentiment-analysis challenges from a Binar Academy bootcamp, rebuilt from scratch because the original notebooks leaked test data into training. Fixing the method — not reaching for a heavier model — is what moved the numbers.

View on GitHub CI runs

What changed

Original recipe compared with the refactored pipeline
Metric Original recipe Refactored Change
Accuracy0.8380.886+4.8 pts
Macro-F10.7970.857+6.0 pts
Neutral-class recall0.730.79+6 pts
Training time~124 s~4 s~30× faster

All figures are leakage-free, from 5-fold stratified cross-validation over about 11,000 rows.

Why it improved

  • The leak came first. The original fitted the vectoriser before splitting, so the model had already seen the test vocabulary. Everything measured after that was optimistic.
  • The right metric. Accuracy flatters an imbalanced three-class problem; macro-F1 exposes how badly the neutral class was doing.
  • Negation kept. Standard stopword lists delete words like tidak, which inverts the sentiment they are meant to measure.
  • A model that suits the data. Sparse, high-dimensional text does not need a heavyweight model — which is also why training dropped to about four seconds.

The two challenges

  • Gold Challenge

    Text cleansing + sentiment API

    An Indonesian text-cleansing module and a Flask plus Swagger REST API that serves the trained model, including bulk prediction from an uploaded CSV.

    Accuracy 0.887 · Macro-F1 0.854
  • Platinum Challenge

    Three-class sentiment classifier

    Negative, neutral and positive classification with a reproducible benchmark that regenerates every number in the repository from scratch.

    Accuracy 0.886 · Macro-F1 0.857
