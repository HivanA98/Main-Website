Gold Challenge Flask · Swagger · scikit-learn

Text cleansing and a sentiment API

Indonesian social-media text is messy: slang, repeated letters and negations that standard stopword lists throw away. This challenge cleans it and serves a sentiment model behind a documented REST API.

View the code CI runs

Three parts

  • cleansing.py — word-level slang normalisation, negation-aware stopword removal, and optional Sastrawi stemming.
  • train_gold.py — leakage-free training that writes model_gold.pkl and tfidf_gold.pkl.
  • app.py — the REST API, with interactive Swagger documentation.

API endpoints

MethodEndpointWhat it does
GET/Health check
POST/cleanseTakes raw text, returns the cleaned version
POST/predictTakes text, returns a label and class probabilities
POST/predict-fileTakes a CSV with a text column, returns a prediction per row
