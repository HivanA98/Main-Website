Techniques on show

  • Page Object Model with chainable actions and reusable components, in every project under cypress/pages.
  • BDD with Gherkin — Scenario Outlines, Data Tables and a tag strategy, in the three BDD projects.
  • Network stubbing with cy.intercept, so the UI can be tested without reaching a protected backend.
  • Fast, stable logins using cy.session() and API login through cy.request.
  • Generated test data from fixtures and Faker, so runs do not collide with each other.
  • API testing in Karate — CRUD, JSON schema validation, chained requests and parallel execution.
  • One reusable workflow for all twelve pipelines, with one status badge per project.
